Methodology and scope

Transparent evidence weighting with explicit limits

This interactive prototype uses a model-generated reference scenario to illustrate signal behavior. Physical sensor equations produce the displayed streams; noise, occlusion, response lag, and coarse resolution are added before features and fusion are computed. These results have not been validated against measurements from a deployed room.

Technical notes and limitations
  • The color model is phenomenological, not a full optical ray tracer.
  • The ToF model is an 8 × 8 overhead depth abstraction with merging and missed regions.
  • CO2 uses a well-mixed-zone mass balance; temperature uses a first-order thermal model.
  • Fusion uses fixed, documented evidence weights and signal-quality checks—not deep learning.
  • Accuracy values characterize this reference case only and should not be interpreted as deployed performance.
